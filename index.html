⚙ Google Apps Script API 연결 설정

Google 스프레드시트와 연동하려면 배포된 웹앱 URL을 입력하세요.

배포 방법
1. Google 스프레드시트 열기
2. 확장 프로그램 → Apps Script
3. 코드 전체 지우고 apps_script.js 내용 붙여넣기
4. 배포 → 새 배포 → 웹 앱 → 실행: 나 / 액세스: 모든 사용자 → 배포
5. 웹앱 URL 복사 후 아래 입력

※ API URL 없이도 이 브라우저에서만 저장되는 로컬 모드로 사용 가능합니다.
